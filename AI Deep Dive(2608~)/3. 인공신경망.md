### 1. 인공 신경망, weight와 bias의 직관적 이해, 인공 신경망은 함수다
 · 핵심 개념  
  - 인공 신경망(ANN)은 입력 벡터 x에 대해 가중치 행렬 W와 편향 벡터 b를 적용해 선형 변환(Wx+b)을 수행하고, 비선형 활성화 함수(예: sigmoid, ReLU)를 통과시켜 출력을 생성  
  - 각 층(layer)은 이러한 연산을 반복적으로 수행하며, 다층 구조를 통해 복잡한 비선형 함수를 근사할 수 있음  
  - 신경망 전체는 입력에서 출력까지 일련의 함수 합성(composition)으로 표현되며, 학습 과정은 이 함수의 파라미터(W, b)를 데이터에 맞게 최적화하는 과정  
  * 구조적 설명:  $$z = Wx + b$$  , $$a = f(z)$$  
  즉 하나의 Layer는  
<p align="center">· Input x  </p>
   <p align="center">↓  </p>
<p align="center">· Linear Transformation($$z = Wx + b$$)  </p>
   <p align="center">↓  </p>
<p align="center">· Activation Function($$a = f(z)$$)  </p>
   <p align="center">↓  </p>
<p align="center">· Output  </p>  

그리고 여러 층을 쌓으면:  
<p align="center">· x  </p>
   <p align="center">↓  </p>
<p align="center">· f₁(x)  </p>
   <p align="center">↓  </p>
<p align="center">· f₂(f₁(x))  </p>
   <p align="center">↓  </p>
<p align="center">· f₃(f₂(f₁(x)))  </p>  
   <p align="center">↓  </p>
<p align="center">· ŷ  </p>  
그래서 예전에 배웠던 함수와 함수의 합성, 그리고 Chain Rule이 여기서 실제로 연결됌


### 2. 선형 회귀, 개념부터 알고리즘까지
 · 핵심 개념  
  - 선형 회귀는 y = Wx + b 형태로 입력과 출력의 선형 관계를 모델링함  
  - 손실 함수로 평균제곱오차(MSE, Mean Squared Error)를 사용하며, 이는 예측값과 실제값의 차이 제곱의 평균  
  - 파라미터(W, b)는 손실 함수를 최소화하는 방향으로 업데이트되며, 이를 위해 미분(gradient)을 계산함  
  - 실제 알고리즘 구현에서는 초기 파라미터 설정, 반복적 업데이트, 수렴 조건 등을 고려  
    * 구조적 설명:  
    <p align="center"> Input x  </p>
   <p align="center">↓  </p>
<p align="center"> ŷ = Wx + b  </p>
   <p align="center">↓  </p>
<p align="center"> Prediction ŷ  </p>
   <p align="center">↓  </p>
<p align="center"> 실제 정답 y와 비교  </p>  
   <p align="center">↓  </p>
<p align="center"> Loss  </p>  
예를 들어 $$\hat{y} = Wx + b$$  그 후 예측값과 실제제값의 차이를 계산.  
MSE라면: $$L = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$  

  
### 3. Gradient descent (경사 하강법)
 · 핵심 개념  
  - 경사 하강법은 손실 함수의 기울기(gradient)를 계산해 파라미터를 손실이 감소하는 방향으로 이동시키는 최적화 알고리즘  
  - 파라미터 업데이트 식은 W_new = W_old - η * ∇W L(W), 여기서 η는 학습률(learning rate), ∇W L(W)는 W에 대한 손실 함수의 기울기  
  - 학습률이 너무 크면 발산, 너무 작으면 수렴 속도가 느려지는 문제가 발생할 수 있음
  - 실제 적용 시, 초기값 설정, local minima, saddle point, 수렴 조건 등 다양한 이슈가 존재하며, 이를 해결하기 위한 다양한 변형(예: momentum, adaptive learning rate)이 연구되고 있음  

    * Gradient descent의 흐름  
    <p align="center">① Input  </p>
   <p align="center">↓  </p>
<p align="center"> ② Neural Network  </p>
   <p align="center">↓  </p>
<p align="center"> ③ Prediction  </p>
   <p align="center">↓  </p>
<p align="center"> ④ Loss 계산  </p>
   <p align="center">↓  </p>
<p align="center"> ⑤ Backpropagation  </p>
   <p align="center">↓  </p>
<p align="center"> ⑥ Gradient 계산  </p>
   <p align="center">↓  </p>
<p align="center"> ⑦ Gradient Descent  </p>
   <p align="center">↓  </p>
<p align="center"> ⑧ Parameter Update  </p>
   <p align="center">↓  </p>
<p align="center"> 다시 Input  </p>   
즉, Backpropagation은 Gradient를 계산하는 과정이고, Gradient Descent는 계산된 Gradient를 이용해 Parameter를 업데이트하는 방법

▷ 오늘 배운 개념 중에서 가장 핵심적인 개념 하나를 골라서 다음 형태로 설명
- 이 개념은 무엇인가?  
 → Gradient descent는 손실 함수의 기울기를 계산하여 파라미터 손실이 감소하는 방향으로 이동시키는 알고리즘임  
- 왜 필요한가?  
 → Loss(cost)를 최소화 하는 최적의 해 를 도출하기 위해 가장 효과적인 방법으로 낮은 비용과 시간을 들여 문제를 해결할 수 있는 방법임.  
- 딥러닝에서 어디에 사용되는가?  
 → Gradient Descent는 Prediction 과정에서 사용되는 것이 아니라, Prediction 이후 계산된 Loss와 Backpropagation을 통해 얻은 Gradient를 이용하여 Weight와 Bias 등의 Parameter를 업데이트하는 최적화 알고리즘이다.
