### 1. 인공 신경망, weight와 bias의 직관적 이해, 인공 신경망은 함수다
 · 핵심 개념  
  - 인공 신경망(ANN)은 입력 벡터 x에 대해 가중치 행렬 W와 편향 벡터 b를 적용해 선형 변환(Wx+b)을 수행하고, 비선형 활성화 함수(예: sigmoid, ReLU)를 통과시켜 출력을 생성  
  - 각 층(layer)은 이러한 연산을 반복적으로 수행하며, 다층 구조를 통해 복잡한 비선형 함수를 근사할 수 있음  
  - 신경망 전체는 입력에서 출력까지 일련의 함수 합성(composition)으로 표현되며, 학습 과정은 이 함수의 파라미터(W, b)를 데이터에 맞게 최적화하는 과정  
  * 구조적 설명:  $$z = Wx + b$$  , $$a = f(z)$$  
  즉 하나의 Layer는  
<p align="center">· Input x  </p>
   <p align="center">↓  </p>
<p align="center">· Linear Transformation($$z = Wx + b$$)  </p>
   <p align="center">↓  </p>
<p align="center">· Activation Function($$a = f(z)$$)  </p>
   <p align="center">↓  </p>
<p align="center">· Output  </p>  

그리고 여러 층을 쌓으면:  
<p align="center"> x  </p>
   <p align="center">↓  </p>
<p align="center"> f₁(x)  </p>
   <p align="center">↓  </p>
<p align="center"> f₂(f₁(x))  </p>
   <p align="center">↓  </p>
<p align="center"> f₃(f₂(f₁(x)))  </p>  
   <p align="center">↓  </p>
<p align="center"> ŷ  </p>  
그래서 예전에 배웠던 함수와 함수의 합성, 그리고 Chain Rule이 여기서 실제로 연결됌


### 2. 선형 회귀, 개념부터 알고리즘까지
 · 핵심 개념  
  - 선형 회귀는 y = Wx + b 형태로 입력과 출력의 선형 관계를 모델링함  
  - 손실 함수로 평균제곱오차(MSE, Mean Squared Error)를 사용하며, 이는 예측값과 실제값의 차이 제곱의 평균  
  - 파라미터(W, b)는 손실 함수를 최소화하는 방향으로 업데이트되며, 이를 위해 미분(gradient)을 계산함  
  - 실제 알고리즘 구현에서는 초기 파라미터 설정, 반복적 업데이트, 수렴 조건 등을 고려  
    * 구조적 설명:  
<p align="center"> Input x  </p>
   <p align="center">↓  </p>
<p align="center"> ŷ = Wx + b  </p>
   <p align="center">↓  </p>
<p align="center"> Prediction ŷ  </p>
   <p align="center">↓  </p>
<p align="center"> 실제 정답 y와 비교  </p>  
   <p align="center">↓  </p>
<p align="center"> Loss  </p>  
예를 들어 ŷ = Wx + b  그 후 예측값과 실제제값의 차이를 계산.  

  
### 3. Gradient descent (경사 하강법)
 · 핵심 개념  
  - 경사 하강법은 손실 함수의 기울기(gradient)를 계산해 파라미터를 손실이 감소하는 방향으로 이동시키는 최적화 알고리즘  
  - 파라미터 업데이트 식은 W_new = W_old - η * ∇W L(W), 여기서 η는 학습률(learning rate), ∇W L(W)는 W에 대한 손실 함수의 기울기  
  - 학습률이 너무 크면 발산, 너무 작으면 수렴 속도가 느려지는 문제가 발생할 수 있음
  - 실제 적용 시, 초기값 설정, local minima, saddle point, 수렴 조건 등 다양한 이슈가 존재하며, 이를 해결하기 위한 다양한 변형(예: momentum, adaptive learning rate)이 연구되고 있음  

    * Gradient descent의 흐름

   <p align="center">↓  </p>
<p align="center"> ④ Loss 계산  </p>
   <p align="center">↓  </p>
<p align="center"> ⑤ Backpropagation  </p>
   <p align="center">↓  </p>

즉, Backpropagation은 Gradient를 계산하는 과정이고, Gradient Descent는 계산된 Gradient를 이용해 Parameter를 업데이트하는 방법

- 이 개념은 무엇인가?  
 → Gradient descent는 손실 함수의 기울기를 계산하여 파라미터 손실이 감소하는 방향으로 이동시키는 알고리즘임  
- 왜 필요한가?  
 → Loss(cost)를 최소화 하는 최적의 해 를 도출하기 위해 가장 효과적인 방법으로 낮은 비용과 시간을 들여 문제를 해결할 수 있는 방법임.  
- 딥러닝에서 어디에 사용되는가?  
 → Gradient Descent는 Prediction 과정에서 사용되는 것이 아니라, Prediction 이후 계산된 Loss와 Backpropagation을 통해 얻은 Gradient를 이용하여 Weight와 Bias 등의 Parameter를 업데이트하는 최적화 알고리즘이다.

### 4. 가중치 초기화 기법  
 · 핵심 개념  
  - 가중치 초기화는 딥러닝 학습의 수렴 속도와 안정성에 결정적 영향  
  - 모든 가중치를 0으로 초기화하면 symmetry breaking*이 일어나지 않아 학습 불가  
   * Symmetry Breaking: 처음부터 각 뉴런이 서로 다른 초기값을 갖게 하여, 학습 과정에서 서로 다른 특징을 학습할 수 있도록 대칭성을 깨는 것  
   EX) 만약 모든 뉴런의 Weight가 동일하다면:  
    Neuron 1 → 같은 입력 → 같은 Weight → 같은 Output  
    Neuron 2 → 같은 입력 → 같은 Weight → 같은 Output  
    Neuron 3 → 같은 입력 → 같은 Weight → 같은 Output  
    ∴ Backpropagation을 해도 Gradient까지 동일하게 나올 가능성이 높음, 그러면 W₁ = W₂ = W₃ 상태가 계속 유지되고 여러 뉴런이 있어도 전부 같은 특징만 학습하는 문제 발생.
    ##### ☞ 이때문에 초기화 단계에서 작은 랜덤값을 줌  

  - 일반적으로 작은 난수(정규분포, 균등분포)로 초기화  
  - Xavier(Glorot) 초기화: 입력/출력 노드 수 기반 분산 조정, sigmoid/tanh 계열에 적합  
  - He 초기화: ReLU 계열에 적합, 입력 노드 수 기반 분산 사용  

### 5. GD vs SGD  
 · GD(Gradient Descent)  
  - 전체 데이터셋에 대해 loss의 gradient 계산, 한 번에 파라미터 업데이트  
 · SGD(Stochastic Gradient Descent)  
  - 데이터 한 샘플마다 gradient 계산 및 업데이트, 노이즈로 인해 local minima 탈출 가능     
  * GD는 계산량이 많고, SGD는 불안정하지만 빠른 업데이트가 장점.  


### 6. mini-batch SGD  
 · 핵심 개념  
  - 데이터셋을 작은 batch로 나누어 각 batch마다 gradient 계산 및 업데이트  
  - GD와 SGD의 장점 결합: 계산 효율성, 메모리 사용 최적화, 병렬화 가능.  
  - Batch size에 따라 학습 안정성, 수렴 속도, 일반화 성능에 영향.

### 7. Momentum / RMSProp  
 · Momentum  
  - 이전 gradient의 관성을 반영해 local minima에서 빠져나오고, 진동 억제    
 
 · RMSProp  
  - 각 파라미터별로 gradient의 제곱의 이동평균을 사용해 학습률 자동 조정, 학습 안정성 향상.    
  * 두 기법 모두 SGD의 단점을 보완하며, 실제로는 Adam 등과 결합해 사용

### 8. Adam
 · 이전에 학습한 momentem과 RMSProp 의 장점을 합쳐놓은 방법.  
  - 🔍모멘텀은 진동을 줄이고 빠르게 최적점에 접근하게 해주고, 🔍RMSProp은 각 파라미터별로 학습률을 조정해 불안정한 방향의 이동을 막아줌. 따라서 장점만을 가진 Adam은 결합 시 빠른 수렴과 안정적인 학습이 동시에 가능  
  ** (Adam은 기본적으로 두 가지 정보를 함께 사용  
  Momentum 계열 → Gradient의 1차 모멘트(평균) 를 추적  
  RMSProp 계열 → Gradient의 2차 모멘트(제곱 평균) 를 추적  
그래서 단순히 "Momentum + RMSProp"이라고 외우기보다는: Adam은 Gradient의 1차 모멘트와 2차 모멘트를 각각 추적하여, 각 Parameter에 대해 적응적으로 업데이트하는 Optimizer  

 ※ 오늘의 요약  
Momentum = Gradient의 방향/관성을 이용  

RMSProp = Gradient 크기에 따라 Parameter별 업데이트 크기를 조절  

Adam = 두 정보를 함께 사용하여 Parameter를 적응적으로 업데이트
