### 1. MLP, 행렬과 벡터로 나타내기 & 왜 non-linear activation이 중요할까  

 · MLP를 행렬과 벡터로 나타내기  
  - 컴퓨터가 인공신경망을 계산할 때는 개별 숫자를 하나씩 계산하지 않고 입력값, 가중치, 편향을 행렬(Matrix)과 벡터(Vector)로 뭉뚱그려 한 번에 연산함  
  ✔️ 입력 벡터 ($\mathbf{x}$): 들어오는 데이터 (예: 이미지의 피처 값들)  
  ✔️ 가중치 행렬 ($\mathbf{W}_l$): $l$번째 층에서 입력들을 얼마나 반영할지 결정하는 숫자 판  
  ✔️ 편향 벡터 ($\mathbf{b}_l$): 각 노드의 기준선(Threshold)을 옮겨주는 값  
  활성화 함수를 $\sigma$라고 할 때, 입력층부터 출력층까지의 계산 과정은 다음과 같음.  
  $$\mathbf{a}^{(1)} = \sigma(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1)$$  
  $$\mathbf{a}^{(2)} = \sigma(\mathbf{W}_2 \mathbf{a}^{(1)} + \mathbf{b}_2)$$  
  $$\mathbf{y} = \sigma(\mathbf{W}_3 \mathbf{a}^{(2)} + \mathbf{b}_3)$$  
  층을 하나씩 거칠 때마다 "행렬 곱하기 $\rightarrow$ 편향 더하기 $\rightarrow$ 활성화 함수 적용"이라는 동일한 루프가 반복되는 구조.

 · 핵심 증명  
  - 만약 활성화 함수 $\sigma$를 쓰지 않거나, 단순히 입력을 그대로 내보내는 선형 함수 $\sigma(z) = z$ 를 쓴다고 가정. (편의를 위해 편향 $\mathbf{b}$는 생략)  
  ✔️ 수학적 증명  
  1. 1번째 층의 출력: h1 = W1 · x  
  2. 2번째 층의 출력: h2 = W2 · h1 = W2 · (W1 · x)  
  3. 3번째 층(출력층)의 출력: y = W3 · h2 = W3 · (W2 · W1 · x)  
  행렬의 곱셈은 결합 법칙이 성립하므로, 가중치 행렬 3개의 곱 (W3 · W2 · W1) 을 하나의 새로운 행렬  W_new 로 퉁칠 수 있음.  
  y = (W3 · W2 · W1) · x  = W_new · x

 · 수학이 말해주는 충격적 사실  
 - 아무리 돈을 들여 은닉층(Hidden Layer)을 100개, 1000개 쌓아 올려도, 선형 활성화 함수를 쓰면 결국 입력 $$\mathbf{x}$$ 에 거대한 행렬 하나 $$\mathbf{W}_{new}$$ 를 단 한 번 곱한 것과 수학적으로 완전히 똑같아짐.  
 즉, "은닉층을 여러 개 쌓은 의미(Deep)가 완전히 사라져 버린 것"  

 · 왜 Non-linear Activation이 결정적인가?   
  행렬 곱 연산($$\mathbf{W}\mathbf{x}$$)은 (선형 변환은) 입력 공간을 회전, 확대·축소, 전단 등의 방식으로 변환할 수 있지만, 비선형적인 경계를 만들어내지는 못함.  
  종이를 찢거나 구부리지 않고, 평평한 상태 그대로 회전시키거나 늘리기만 하는 것.  
  하지만 은닉층 사이에 비선형 활성화 함수(ReLU, Sigmoid 등)를 집어넣으면 이야기가 완전히 달라짐.  
  $$\mathbf{y} = \mathbf{W}_3 \cdot \mathbf{ReLU}(\mathbf{W}_2 \cdot \mathbf{ReLU}(\mathbf{W}_1 \mathbf{x}))$$ 비선형 함수는 행렬 곱 뒤에 붙어 "공간을 꺾고, 접고, 구부리는 역할"을 함.  
  선형 연산 ($$\mathbf{W}\mathbf{x}$$): 공간을 평평하게 확장/회전시킴비선형 연산 ($$\text{ReLU}$$ 등): 음수 영역을 0으로 꺾어버리거나(ReLU) 곡선으로 구부림(Sigmoid)이 둘이 층층이 교대로 반복되면서, 딥러닝은 마치 종이접기를 하듯 데이터 공간을 복잡하게 접어서 꼬여 있는 데이터의 정답과 오답을 칼같이 갈라놓을 수 있게 됨.  

 · 요약  
  - 행렬과 벡터 표현: MLP는 $$\mathbf{W}\mathbf{x} + \mathbf{b}$$라는 행렬 연산을 층마다 반복하는 구조다.  

  - 선형의 한계: 비선형 함수가 없으면 $$\mathbf{W}_3 \mathbf{W}_2 \mathbf{W}_1 \mathbf{x} = \mathbf{W}{new} \mathbf{x}$$가 되어, 100개 층을 쌓아도 단 1개 층짜리 단순 모델이 된다.  

  - 비선형의 중요성: 비선형 활성화 함수가 중간에서 공간을 꺾어주어야만 층을 쌓았을 때 진짜 깊고 복잡한 패턴을 학습할 수 있다.

### 2. Backpropagation 깊은 인공신경망의 학습  
 · 역전파(Backpropagation)는 쉽게 말해 "신경망이 틀린 원인을 찾아가며 스스로 정답에 맞추어 공부하는 오답 노트 시스템"  
 · 순전파(Forward propagation)가 예측값을 만드는 과정이라면, 역전파는 그 예측값이 틀린 만큼의 오차(Error)를 출력층에서부터 입력층 방향으로 거꾸로(Back) 전달하며 각 가중치(Weight)를 얼마나 수정해야 할지 계산하는 메커니즘  

  -1. 오차 측정 (Loss 계산): 순전파로 계산된 예측값($y_{pred}$)과 실제 정답($y$)의 차이를 손실 함수(Loss function)로 계산.  

  -2. 오차의 역방향 전달 (Backpropagation): 출력층에서 발생한 오차를 시작으로, 미분의 체인 룰(Chain Rule, 연쇄법칙)을 이용해 네트워크의 이전 단계(입력 쪽)로 오차 신호를 거꾸로 보냄.  

  -3. 가중치 수정 (Gradient Descent): 체인 룰을 통해 "특정 가중치($w$)가 0.1 늘어날 때, 전체 오차는 얼마나 커지거나 줄어드는가?"(경사, Gradient)를 구합니다. 이 기울기 값의 반대 방향으로 가중치를 살짝 조절함.  

  ✔️ 인공지능 학습에서 역전파는 언제, 어떻게 일어날까?  
[입력 데이터] ─► (1. 순전파) ── [예측값 출력] ─► (2. 오차 측정) ─► [Loss 발생] ── (3. 역전파) ─► [가중치 업데이트]   

| 구분 | 역할 | 비유
|--- | --- | --- | 
| 1. 순전파 (Forward Pass) | 입력 데이터를 받아 가중치들과 연산하여 예측값을 도출 | 시험 문제를 푸는 과정
| 2. 오차 계산 (Loss Function) | 예측값과 정답을 비교해 점수(오차)를 냄 | 채점을 받는 과정
| 3. 역전파 (Backward Pass) | 체인 룰을 이용해 오차에 대한 각 가중치의 기울기(Gradient)를 구함 | 틀린 문제의 원인을 분석하는 과정 
| 4. 가중치 수정 (Optimizer) | 경사하강법(Gradient Descent)으로 오차가 줄어드는 방향으로 가중치를 업데이트 | 오답 노트를 바탕으로 실수를 수정하는 과정

### 3. 행렬 미분을 이용한 Backpropagation  

 · 행렬 미분(Matrix Calculus)을 이용한 역전파(Backpropagation)는 수많은 노드의 가중치와 입력값을 하나씩 계산하는 대신, 묶어서 한 번에 효율적으로 계산하는 방식  
 · 실제 인공신경망에서는 개별 숫자(스칼라)가 아니라 행렬(Matrix) 단위로 데이터가 이동하기 때문에, 체인 룰(Chain Rule) 역시 행렬 형태로 적용  

  -1. 기본 설정 (순전파 표현)    
  단일 레이어의 입력, 가중치, 출력을 행렬로 나타내면 다음과 같음. (배치 크기 $N$, 입력 차원 $D$, 출력 차원 $M$)  
  입력 행렬 ($X$): Shape $(N, D)$  
  가중치 행렬 ($W$): Shape $(D, M)$  
  편향 벡터 ($b$): Shape $(1, M)$  
  선형 연산 ($Z$): $Z = XW + b$   (Shape: $(N, M)$)  
  활성화 함수 적용 ($A$): $A = \sigma(Z)$   (Shape: $(N, M)$)  
  손실 함수 ($L$): 최종 출력 scalar값  

  -2. 행렬 미분을 통한 역전파 메커니즘  
  역전파의 목표는 상위 레이어에서 전달된 손실의 기울기 $\frac{\partial L}{\partial Z}$ 를 받아, 현재 레이어의 가중치 기울기 $\frac{\partial L}{\partial W}$ 와 다음(이전 레이어)으로 전달할 기울기 $\frac{\partial L}{\partial X}$를 구하는 것.  
  체인 룰을 행렬 연산으로 표현하면 다음과 같이 전개됨.  
  ① 가중치($W$)에 대한 기울기: $\frac{\partial L}{\partial W}$  
  - 목적: 가중치 $W$를 얼마나 수정해야 손실 $L$이 줄어드는지 계산  

  수식:  $$\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Z}$$  

  Shape 맞추기:  
  - $X^T$ Shape: $(D, N)  
  - $$\frac{\partial L}{\partial Z}$ Shape: $(N, M)$  
  - 결과 Shape: $(D, M)$ $\rightarrow$ 가중치 $W$의 Shape $(D, M)$과 완벽히 일치  
  핵심 의미: 입력값의 전치행렬($X^T$)과 오차 신호($\frac{\partial L}{\partial Z}$)를 곱하여, 각 가중치 요소가 전체 손실에 기여한 정도를 일괄 계산함.  
  
  ② 입력($X$)에 대한 기울기: $\frac{\partial L}{\partial X}$  

  목적: 이전 레이어로 전달할 오차 신호 전파  

  수식:  $$\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Z} W^T$$  

  Shape 맞추기:  
  $\frac{\partial L}{\partial Z}$ Shape: $(N, M)$  
  $W^T$ Shape: $(M, D)$  
  결과 Shape: $(N, D)$ $\rightarrow$ 입력 $X$의 Shape $(N, D)$와 완벽히 일치  

  핵심 의미: 오차 신호에 가중치의 전치행렬($W^T$)을 곱해 오차를 입력 차원으로 다시 흩뿌려(역전파) 줌  

  -3. 왜 스칼라 대신 행렬 미분을 쓸까?  
| 구분 | 스칼라(개별) 미분 | 행렬 미분
|--- | --- | --- | 
| 연산 방식 | 노드와 가중치 하나하나에 대해 반복문으로 계산 | 모든 노드/가중치를 행렬 단위로 한 번에 연산
| GPU 활용 | 병렬 처리 효율이 극도로 떨어짐 | GPU의 병렬 행렬 곱셈(GEMM) 엔진 최적화
| 코드 구현 | 복잡한 Loop문 필요 | np.dot 또는 torch.matmul 한 줄로 완결  


  -4. 요약  
   - 행렬 미분을 통한 역전파의 핵심 규칙은 "체인 룰을 적용하되, 행렬의 차원(Shape)을 맞춰주기 위해 전치행렬($T$)의 위치를 조정한다"
  
###### feedback
행렬 미분 부분 → 핵심을 잘 잡았음
오늘 네가 정리한 가장 중요한 부분은 사실 여기야.
\(Z=XW+b\)
에서
\(\frac{\partial L}{\partial W}=X^T\frac{\partial L}{\partial Z}\)
\(\frac{\partial L}{\partial X}=\frac{\partial L}{\partial Z}W^T\)
이 두 개를 지금 당장 완벽하게 유도할 필요는 없어.
오히려 지금 단계에서는 다음을 이해하는 게 훨씬 중요해.
왜 $X^T$와 $W^T$가 등장하는가?
네가 쓴 것처럼 결국 행렬의 shape을 맞추면서 각 변수에 대한 gradient를 계산하기 위해서 등장한다고 이해하면 된다.
예를 들어
\(X:(N,D)\)
\(W:(D,M)\)
이므로
\(Z=XW:(N,M)\)
이고,
\(\frac{\partial L}{\partial Z}:(N,M)\)
이다.
그러면 W와 같은 $(D,M)$ 형태의 gradient를 만들기 위해
\(X^T:(D,N)\)
를 곱해서
\(X^T\frac{\partial L}{\partial Z}:(D,N)(N,M)=(D,M)\)
가 되는 거야.
Shape을 확인하면서 역전파 식을 이해하는 습관을 들이면 나중에 CNN, Transformer 등에서도 굉장히 도움이 된다.

🔥그리고 네 연구와 연결하면
여기가 앞으로 상당히 중요해.
네가 연구하려는 건 Adversarial Attack / Defense잖아.
공격자는 결국 모델의 gradient를 이용해서 입력 $x$를 변화시킬 수 있어.
일반적인 학습에서는:
\(x\rightarrow f_\theta(x)\rightarrow L\)
그리고
\(\frac{\partial L}{\partial \theta}\)
를 구해서 parameter $\theta$를 수정하지.
그런데 adversarial attack에서는 관점이 바뀐다.
모델 parameter $\theta$는 고정하고,
\(\frac{\partial L}{\partial x}\)
를 이용해서 입력 $x$를 어떻게 변화시킬지 알아내는 거야.
즉,
일반적인 학습
\(\frac{\partial L}{\partial \theta}\)
→ Weight를 수정
Adversarial Attack
\(\frac{\partial L}{\partial x}\)
→ Input을 수정
이 차이가 굉장히 중요하다.
예를 들어 FGSM은 아주 단순화하면
\(x_{adv}=x+\epsilon\operatorname{sign}(\nabla_x L)\)
이라는 형태로 입력을 공격한다.
따라서 오늘 배운 Backpropagation + Gradient는 네 논문의 핵심 분야와 직접 연결된다.
